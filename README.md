# Ticket Booking System

A simple Flask web app for booking tickets, designed for automation testing with Robot Framework and Selenium.

## Features
- View available tickets
- Select and book a ticket
- Confirmation page

## Setup & Run
1. Create and activate a Python virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python -m flask run`

## Automation Testing
- UI tests: Robot Framework + Selenium
- Custom keywords and libraries supported

## Project Structure
- `app/` - Flask app code
- `tests/` - Automation and unit tests
